🧑 Characters
64 slots · base 0x175C4 · stride 0x4A0. Stats = 7 × 8 bytes from +0x0C: STR AGI SEN VIR INT CON SPI.
⚔️ Formation
5 rows × 5 slots (captain + 4 units). Roster at 0x592A, 5 entries × 0x1C bytes. Unit IDs at +0x0A–+0x16.
ℹ️ Each row = one roster entry. The first non-FF WORD at +0x0A is the row captain. The following WORDs are units. 0xFFFF = empty slot. Row 0 is always the active formation in all samples.

💼 Job Progression
Per-character job data at base 0x2A460, stride 0x124, 12 blocks. Job unlock flags at block+0x20 (30 bytes). XP spent at block+0x44. Stat XP at +0x4C–+0x6C.
ℹ️ Job IDs: Female base 2,4,6,8,10 · Female light (+10): 12,14,16,18,20 · Female dark (+20): 22,24,26,28,30 · Male versions subtract 1 from each. Current job at block+0x01 (high byte of first WORD). Setting all 30 unlock-flag bytes to 0x01 unlocks all jobs.
✨ Skill Grid
Per-character skill tree at char+0xB8. 84 cells (7 rows × 12 cols), 12 bytes each — first DWORD = status. Click a cell to cycle its status.
ℹ️ 40 skill slots were reshuffled by the developers at some point and no longer sit at the position their column-major index would suggest. This grid applies a verified position fix (derived from a full memory→display cross-reference) so what you see here matches the in-game layout exactly.

💬 Character Relationships
Mood relationship matrix at 0x2ECCC. Each character has 64 relationship scores toward every other char. Entry layout: [SHORT id][BYTE×2 misc][BYTE×64 scores] where score[j] = feeling toward char j+1 (self = 0).
ℹ️ Scores: 0=hostile, 30=dislike, 50=neutral, 70=friendly, 100=best friends. The first 2 bytes of the 64-value array (bytes[2..3] of entry) are an unknown pair — the score for char 1 starts at byte[3] based on position matching char_id−1 within the array.
